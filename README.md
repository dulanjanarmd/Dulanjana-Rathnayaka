# Dulanjana Rathnayaka - Personal Portfolio

This is the personal portfolio of Dulanjana Rathnayaka, built using **React** and bundled with **Parcel**.

## Live Demo
You can view the live version of this portfolio here: [https://dulanjanarmd.github.io/Dulanjana-Rathnayaka](https://dulanjanarmd.github.io/Dulanjana-Rathnayaka)

## Technologies Used
- React (v18)
- Parcel
- ESLint & Prettier
- GitHub Pages (for deployment)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/dulanjanarmd/Dulanjana-Rathnayaka.git
   ```
2. Navigate into the project directory:
   ```sh
   cd Dulanjana-Rathnayaka
   ```
3. Install the dependencies:
   ```sh
   npm install
   ```

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in the development mode.
Open [http://localhost:1234](http://localhost:1234) to view it in your browser. The page will reload when you make changes.

### `npm run build`
Builds the app for production to the `dist` folder.
It correctly bundles React in production mode and optimizes the build for the best performance.

### `npm run predeploy`
Prepares the build for deployment by setting the public URL to `/Dulanjana-Rathnayaka/`.

### `npm run deploy`
Deploys the `dist` folder to the `gh-pages` branch, making it live on GitHub Pages.
